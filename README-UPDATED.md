# Hurricane Graphics: Updated

Provides the original Hurricane graphics assets for compatible mods. Install it when another mod requires this asset package.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using hurricane-graphics can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ hurricane-graphics ](https://mods.factorio.com/mod/hurricane-graphics). Original author credits and applicable license notices are retained in the source package.
